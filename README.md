# foss-earth/.github

Shared community files for every repository in the
[foss-earth](https://github.com/foss-earth) organization. GitHub shows them on
each repository that doesn't have its own copy.

- [Contributing](CONTRIBUTING.md), including how versions are named
- [Security](SECURITY.md)
- [Agent instructions](AGENTS.md), which each repository's AGENTS.md points to
